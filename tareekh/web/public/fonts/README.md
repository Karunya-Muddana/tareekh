Optional display font.

Tareekh uses an Indic-style display face in three places only: the wordmark, the weekday on Today, and the
sign-in hero. Samarkan (Titivillus) is shareware and needs a license for commercial use, so it is not
committed. Put a licensed copy here as `samarkan.woff2` (convert a .ttf with any woff2 tool) and it switches on by itself.
Without it, those places fall back to Instrument Serif with a headline bar.
