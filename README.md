# Tareekh

**Practice memory for Indian litigators, built on [Hindsight](https://hindsight.vectorize.io).**

A civil case in India runs for years across dozens of short hearings. What happened at each one lives in the lawyer's
diary, his junior's typed notes, certified copies of the court's order sheet, and a pile of documents from clients.
Tareekh takes those as they are (phone photos, scans, .txt, .docx), files each hearing under the right case, and
stores it in Hindsight. Then the lawyer can ask "what did Srinivas say about his share?" and get the answer with the
source note cited.

It remembers; it does not give legal advice.

> Built for the *AI Agents That Learn Using Hindsight* hackathon. "Tareekh" means *date*, as in *tareekh pe tareekh*.

## The demo practice

Adv. **Aditya Varma** and his junior **Divya**, Visakhapatnam. Two judges: **Murthy sir** (impatient, punishes anything
irregular) and **Padmavathi madam** (gentle, forgiving, sends friends to mediation). Five cases:

| Case | What | Judge |
|---|---|---|
| C1 O.S. 214/2024 | Ramesh vs Srinivas: two old friends fight over shares in 4.20 acres near Bheemili beach | Padmavathi |
| C2 O.S. 57/2025 | Seabreeze Resorts sues to enforce a sale agreement only Srinivas signed | Murthy |
| C3 O.S. 131/2025 | Ramesh sues Seabreeze to stop them fencing the land | Murthy |
| C4 O.S. 302/2025 | Landlady vs tiffin-centre tenant (eviction) | Padmavathi |
| C5 O.S. 88/2025 | Printer vs school (unpaid bills) | Murthy |

What memory has to connect, because no single document says it:

- Srinivas claims **70%** in C1 but tells Murthy sir in C2 they are **equal owners**.
- Seabreeze says "no construction whatsoever" in C3 but "commenced preliminary works in April 2025" in C2.
- The same VRO testifies in C1 and C3.
- Murthy sir's pattern across C2, C3 and C5: "last opportunity" on the second request, costs on the third.
- Open commitments: objections due 30 Sept in C2, and a missed rent instalment in C4.

Data: 50 hearings, 79 uploads (diary photos, typed notes, order-sheet scans, the sale deed, the Seabreeze agreement
with Ramesh's signature column blank, the friends' 2016 letter, 1-B ROR, EC, police receipt, a WhatsApp export).
Generated by `tareekh-data/generator` from `story.py`.

## Run it

Needs Python 3.10+, Docker Desktop, and a Google Cloud project with Vertex AI (`gcloud auth application-default login` once).

```powershell
cd tareekh\backend
copy .env.example .env                                   # set VERTEX_PROJECT
powershell -ExecutionPolicy Bypass -File start.ps1       # Hindsight + API, opens http://127.0.0.1:8000
.venv\Scripts\python scripts\load_backlog.py            # (other terminal) feed the 79 uploads through OCR + memory
```

The page at `http://127.0.0.1:8000` does two things: upload notes (review, then save to memory) and ask questions.
Hindsight's own UI is at `http://localhost:9999`.

To regenerate the data: `cd tareekh-data/generator && python build.py`.

## Layout

```
tareekh/backend/     FastAPI app: ingest (OCR → split per hearing → resolve case) → Hindsight; agent for /ask
tareekh-data/        generator/ (story.py, build.py, render.py), data/ (ground truth), uploads/ (what gets uploaded)
docs/                DEVLOG.md, GLOSSARY.md
```
